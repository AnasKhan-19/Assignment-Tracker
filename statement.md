# Project Statement

## Project Title

Assignment Tracker

## Problem Statement

A college student will always have multiple assignments in various subjects and due dates. It can get hard to keep track of everything and what is completed or not.

The Assignment Tracker is meant to keep everything organized

## Scope

The scope of this project is to keep track of simple assignments for a student.

The application can let the user:

• Add assignments

• Fill in the subject and due date

• Set a priority for the assignment

• Set a description for the assignment

• Search existing assignments

• Mark assignments as completed

• Delete assignments

• Get reminded of overdue assignments

• See assignment statistics

• Store assignments locally in the device

For now, the application will only be used by one person in a single device

## Target Users

The main target users for this application are:

• College students

• School students

• Students with multiple assignments in different subjects

## High-Level Features

1. Assignment Management

Users can add, view, search, complete, and delete assignments.

2. Deadline Tracking

The application will be able to store the assignment deadline and notify the user when an assignment is overdue.

3. Priority

The user will be able to set a priority for each assignment: Low, Medium, and High.

4. Assignment Statistics

The application will have simple statistics that show the amount of total, completed, pending, and overdue assignments.

5. Local Storage

The application will store the assignments in the computer device in a file called `assignments.txt` and be able to retrieve them when needed.

## Technologies

The following technologies will be used to develop the application:

• Python

• Tkinter

• File handling

• Simple date handling

## Project Limitation

For now, the project will only be a simple application that does not require any account, cloud storage, or database.

## Expected Outcome

The expected outcome of the project is to have a simple and handy Python application.
