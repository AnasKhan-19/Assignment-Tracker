#Assignment Monitor

College students can manage their assignments in one place with the help of Assignment Tracker, a simple desktop Python application. It helps the user keep track of assignment details, topics, due dates, priorities, and completion status.

## Characteristics

Add new tasks
Decide on the topic and due date.
Choose the priority of the assignment.
Add a brief description
View assignments that have been saved.
Mark tasks as finished.
When the assignments are no longer needed, delete them.
Look up assignments by subject or title.
Identify the assignments that are past due
Examine basic assignment data
Locally store assignment data.
